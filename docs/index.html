01 / THE TRAP

Four moves can cost 28.

In the default map, crossing three expensive cells takes four moves. Going around takes eight moves and costs only eight. We minimize entry cost, not the number of moves.

02 / THE FAIR COMPARISON

Same map. Same optimal cost.

A* uses Manhattan distance. Every move costs at least one. Both algorithms share the same tie rule: larger cost so far, then smaller cell index. Walls can weaken the heuristic.

03 / READ THE METRIC

Less search ≠ always faster.

Expanded cells count work done by the search. Animation speed is presentation only. This JavaScript demo is separate from the measured Python/C benchmarks in the repository.

فارسی — راهنمای کوتاه

یک نقشه را در هر دو پنل تغییر بده و «Run comparison» را بزن. S شروع و G مقصد است؛ # دیوار است و عدد هر خانه هزینهٔ ورود را نشان می‌دهد. هدف یافتن کم‌هزینه‌ترین مسیر است، حتی اگر طولانی‌تر باشد.

با ابزار Start و Goal ابتدا و انتها را جابه‌جا کن؛ باید در دو خانهٔ جدا باشند. Pause مکث می‌کند و Reset نقشهٔ نمونه را برمی‌گرداند. با تغییر نقشه نتیجهٔ قبلی پاک می‌شود. تعداد گره‌های Expanded معیار جست‌وجو است، نه بنچمارک سرعت Python و C.
