# Maze Signal — مسیر کوتاه‌تر همیشه ارزان‌تر نیست

یک چالش مسیریابی با دو پیاده‌سازی مستقل در **پایتون و C**، همراه با تصویر الگوریتمی، تست و نتایج قابل بازتولید.

![مقایسهٔ فضای جست‌وجو](assets/search.svg)

روی نقشه‌ای با دیوار و زمین‌های هزینه‌دار، از `S` به `G` بروید. حرکت فقط در چهار جهت مجاز است. هدف کمینه کردن مجموع هزینهٔ ورود به خانه‌هاست، نه تعداد قدم‌ها.

در [مثال دام](maps/trap.txt)، مسیر مستقیم با ۴ قدم هزینهٔ ۲۸ دارد؛ مسیر دورتر با ۸ قدم فقط ۸ واحد هزینه دارد.

## اجرای سریع

```bash
python python/solver.py maps/trap.txt astar
python python/solver.py maps/trap.txt dijkstra
```

برای C در ویندوز و PowerShell:

```powershell
New-Item -ItemType Directory -Force build | Out-Null
gcc -std=c11 -O3 -Wall -Wextra -Wpedantic c/solver.c -o build/solver.exe
./build/solver.exe maps/trap.txt astar
python -m unittest discover -s tests -v
```

در لینوکس و مک، پوشه را با `mkdir -p build` بسازید و نام فایل اجرایی را `build/solver` بگذارید.

خروجی JSON شامل هزینهٔ مسیر، تعداد خانه‌های گسترش‌یافته، مسیر و زمان حل است. شمارهٔ خانه‌ها از صفر و به ترتیب سطرهاست. اگر مسیر وجود نداشته باشد، هزینه `null` خواهد بود.

## ایدهٔ الگوریتم

Dijkstra بر اساس هزینهٔ واقعی تا این لحظه جست‌وجو می‌کند. A* تخمین فاصلهٔ منهتن تا هدف را هم اضافه می‌کند. چون هزینهٔ هر قدم حداقل یک است، این تخمین از هزینهٔ واقعی بیشتر نمی‌شود و جواب همچنان بهینه است. جزئیات اثبات، قرارداد ورودی و پیچیدگی در [راهنمای انگلیسی](README.md) آمده است.

## نتایج و اعتبارسنجی

۵۰۰ نقشهٔ تصادفی با بذر ثابت و پنج مثال مشخص، با یک مرجع مستقل Bellman-Ford مقایسه می‌شوند. هر دو زبان و هر دو الگوریتم باید هزینه، مسیر و تعداد گسترش یکسان بدهند. ورودی‌های نامعتبر هم بررسی می‌شوند.

بنچمارک روی نقشهٔ باز، دیوارهای متناوب و زمین وزن‌دار اجرا شده است. [جدول نتایج](results/RESULTS.md)، [دادهٔ خام](results/raw.csv) و [مشخصات محیط](results/environment.json) داخل مخزن هستند. زمان‌ها وابسته به سیستم و روش اندازه‌گیری‌اند؛ تصویر بالای صفحه مربوط به نمونهٔ باز ۳۱×۳۱ است.

بازتولید در ویندوز:

```powershell
python tools/experiment.py --binary build/solver.exe --size 160 --repeat 30 --samples 5
```
